# 療育マップ（千代田区・台東区・中央区）

児童発達支援・放課後等デイサービスの施設と、子どもの発達障害を診る医療機関を地図にまとめたサイトです。

- ピンをタップ → 小さなカードで概要（本文はタップで全文表示）。一覧から施設を選んでも地図の縮尺は変わらない
- 「公式サイトを見る」 → 各施設のHPへ
- 上部のボタンで種類（医療機関を含む）、プルダウンでエリア・得意分野（ことば・運動・感覚統合など）を絞り込み
- 「学校から探す」で区立小・中学校を選ぶと、その学校から徒歩15分以内（直線1km）または送迎ありの施設だけに絞り込み。訪問型は距離に関係なく表示、未就学児向けのみの施設は除外。地図上の「小」「中」マークをタップしても選択可。選択すると地図の下に周辺施設の一覧（徒歩15分以内／送迎あり／訪問型）が出て、行をタップするとその場で詳細が開き、地図は縮尺を変えずにその施設へ移動
- 右下のボタンで一覧表示。一覧は区ごと／種類ごと／名前順／得意分野が多い順に並べ替え可能
- 募集停止・区民限定などの注意点はカードに強調表示

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面（地図・カード・一覧） |
| `facilities.js` | 施設データ。**施設の追加・修正はここだけ** |

## 公開方法（GitHub Pages・無料）

1. GitHubでアカウントを作り、新しいリポジトリ（例: `ryoiku-map`）を Public で作成
2. 「Add file → Upload files」から `index.html` と `facilities.js` をアップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/ryoiku-map/` で公開されます

Netlify Drop（https://app.netlify.com/drop）にフォルダをドラッグするだけでも公開できます。

## 施設の追加・閉室時の削除

閉室した施設は `facilities.js` から該当の1件を削除してください。区の一覧は更新が遅れることがあるので、定期的に各施設の公式サイトも確認すると安心です。


`facilities.js` の配列に1件追加します。緯度経度は国土地理院の住所検索で調べられます:
`https://msearch.gsi.go.jp/address-search/AddressSearch?q=東京都千代田区○○1-2-3`
の結果の `coordinates` が `[経度, 緯度]` です。

```js
{
  name: "施設名",
  ward: "千代田区",                 // 表示する区（FACILITIES_META.areas と同じ表記）
  services: ["jihatsu", "houday"],   // jihatsu=児童発達支援 / houday=放課後等デイ / houmon=居宅訪問型 / hoikuhoumon=保育所等訪問 / clinic=医療機関
  cats: ["lang", "motor"],           // 得意分野: lang=ことば / motor=運動 / sensory=感覚統合 / study=学習 / sst=SST・社会性 / aba=ABA / medcare=医療的ケア / career=就労 / pickup=送迎
  address: "千代田区…",
  tel: "03-xxxx-xxxx",
  lat: 35.69, lng: 139.76,
  age: "未就学児",
  tags: ["個別", "ABA"],
  summary: "支援内容の概要（80字程度）",
  url: "https://...",
  note: ""                          // 任意：募集停止などの注意書き
  // 学校は facilities.js 末尾の window.SCHOOLS に { ward, level: "e"(小)/"j"(中), name, address, lat, lng } で追加
},
```

## データの出典

- 施設一覧: 千代田区「児童福祉法による障害児通所支援サービス」（2025年9月8日更新）
- 施設一覧: 台東区「障害児通所支援（児童発達支援・放課後等デイサービス等）」（2026年8月10日更新）
- 施設一覧: 中央区「区内障害児通所支援事業所一覧」（2026年9月16日掲載）
- 運営状況: 各施設の公式サイトで閉室・休止・移転の告知がないか確認（2026年9月25日）。千代田区の一覧は更新が古く、閉室済みの First Classroom 千代田が残っていたため除外
- 医療機関: 東京都「発達障害者医療機関リスト」と各医療機関の公式サイト。子どもの発達障害の診療を公式サイトで確認できたものだけを掲載（初診受付停止中の医療機関は除外）
- 得意分野: 各施設の公式サイトの記載（タグ・概要）から分類
- 学校: 各区公式サイトの区立小学校・中学校一覧（千代田区・台東区・中央区、計59校）。座標は OpenStreetMap
- 送迎あり: 公式サイトの記載、または療育施設検索サイト「イクデン」の送迎あり一覧（2026年9月26日確認）。送迎範囲・対象校は施設ごとに異なるため要確認
- 徒歩時間: 直線距離×1.2を分速80mで割った目安（徒歩15分≒直線1km）
- 位置: 国土地理院 住所検索API、医療機関は厚生労働省「医療情報ネット」の座標（半蔵門のびすここどもクリニックは同じ街区の分院の座標を使用）
- 概要: 各施設公式サイトの記載を要約（2026年9月確認）
- 地図: 国土地理院 淡色地図 / Leaflet

公開前に掲載施設へ一声かけておくと、内容の誤りや掲載可否を確認できて安心です。
